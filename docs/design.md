# Ivan Bongiovanni design system

Design system of Ivan Bongiovanni's portfolio (https://bongi.dev). A technical document on paper: ink on paper, with small orange 3D agents as the only color.

Live reference: /design-system. Raw markdown: /design-system/design.md. Generated by `bun run design:md` from `app/globals.css` and typed data in `lib/design-system/`. Do not edit by hand.

25 documented components, 36 color tokens, 11 utilities.

## DS-01 Philosophy 哲学

1. **Technical document on paper** 紙. Paper ground, ink type, numbered sheets. Every page reads as a technical document.
2. **80/20 minimalism** 簡. Cut until the remaining 20 percent carries 80 percent of the meaning.
3. **Ink only, clay for agents** 墨. Ink and paper everywhere. Clay orange belongs to the 3D agents alone.
4. **One shared canvas** 一. One WebGL canvas for the whole site. Views track DOM boxes. Never a second Canvas.
5. **Motion with purpose** 動. Motion explains state or shows work. Every animation has a reduced-motion twin.
6. **Less text, more visuals** 視. Labels and short lines. Specimens, 3D and diagrams carry the story.
7. **Hairlines, not shadows** 罫. Radius 0. Rules, hatch and corner marks build structure. No soft shadows.

## DS-02 Color tokens 色彩

Every color is a CSS variable declared in `:root` of `app/globals.css` and exposed to Tailwind through `@theme inline` as `--color-*`. Values are OKLCH. Hex is the sRGB equivalent. Contrast is WCAG 2.x against `--paper` unless the row says `on <token>`, with translucent tokens composited over paper first. Grades: AAA from 7, AA from 4.5, AA large from 3, non-text below 3 (decorative only, never body text).

## DS-04 Spacing and grid 間隔と格子

### Spacing

Tailwind's 4px scale (`--spacing: 0.25rem`). Spacing, sizes and positions are multiples of 4px.

| Step | Example class | Px  | Use                           |
| ---- | ------------- | --- | ----------------------------- |
| 1    | `p-1`         | 4   | Hairline gaps, icon nudges    |
| 2    | `p-2`         | 8   | Chip gaps, label to value     |
| 3    | `p-3`         | 12  | Inner stacks, hit-area growth |
| 4    | `p-4`         | 16  | Cell padding, page gutter     |
| 5    | `p-5`         | 20  | Cell padding from md          |
| 6    | `p-6`         | 24  | Panel stack, column gutter    |
| 8    | `p-8`         | 32  | Page gutter from md           |
| 11   | `p-11`        | 44  | Minimum touch target          |
| 16   | `p-16`        | 64  | Gap between sections          |
| 24   | `p-24`        | 96  | Page bottom padding           |

### Radius

Radius is `--radius: 0`. Every step derives from it, so every corner is square.

| Class         | Variable       | Factor | Px  |
| ------------- | -------------- | ------ | --- |
| `rounded-sm`  | `--radius-sm`  | 0.5    | 0   |
| `rounded-md`  | `--radius-md`  | 0.75   | 0   |
| `rounded-lg`  | `--radius-lg`  | 1      | 0   |
| `rounded-xl`  | `--radius-xl`  | 1.5    | 0   |
| `rounded-2xl` | `--radius-2xl` | 2      | 0   |

### Document grid

- Container: `mx-auto w-full max-w-screen-2xl px-4 md:px-8`.
- 12 columns from lg. Dossier spans 4 and is sticky. Content spans 8.
- Column gutter `gap-x-6`. Sections stack with `gap-16`. Panels stack with `gap-6`.
- Cells use hairline right and bottom borders inside a container with top and left borders.

### Breakpoints

| Name | Min width px | What changes |
| --- | --- | --- |
| `sm` | 640 | Companion walks between waypoints. Below it sits small and swaps |
| `md` | 768 | Page gutter 16 to 32. Chip targets shrink from 44 to 32 |
| `lg` | 1024 | 12-column grid, sticky dossier |
| `xl` | 1280 | Largest hero title |
| `2xl` | 1536 | Container stops growing at 1536 |

## DS-05 Utilities ユーティリティ

Utilities are defined once with `@utility` in `app/globals.css`. Use them in markup. Do not write ad-hoc CSS classes.

### `label`

Geist Mono, 10px, tracked caps. Annotations, headings, chips.

```tsx
<span className="label text-mist">Doc</span>
```

```css
@utility label {
  font-family: var(--font-mono);
  font-size: 0.625rem;
  line-height: 0.875rem;
  letter-spacing: 0.16em;
  text-transform: uppercase;
}
```

### `display`

Zen Kaku light, tight tracking, 0.88 leading, balanced.

```tsx
<h1 className="display text-ink text-8xl">Title</h1>
```

```css
@utility display {
  font-family: var(--font-sans);
  font-weight: 300;
  letter-spacing: -0.05em;
  line-height: 0.88;
  text-wrap: balance;
}
```

### `jp`

Noto Sans JP, normal tracking, no case transform.


```css

  font-family: var(--font-jp);
  letter-spacing: normal;
  text-transform: none;
```


## DS-08 Motion 動作

### Easings

Declared in `@theme inline`, available as `ease-*` utilities.

| Token | Class | Curve | Use |
| --- | --- | --- | --- |
| `--ease-mechanical` | `ease-mechanical` | `cubic-bezier(0.7, 0, 0.2, 1)` | State flips: hover, press, focus, ink swap. Pairs with 100ms. |
| `--ease-out-quart` | `ease-out-quart` | `cubic-bezier(0.25, 1, 0.5, 1)` | Fades and arrow nudges that settle softly. 150 to 500ms. |
| `--ease-out-quint` | `ease-out-quint` | `cubic-bezier(0.22, 1, 0.36, 1)` | Reveals and underline draws. Pairs with 300ms. |
| `--ease-out-expo` | `ease-out-expo` | `cubic-bezier(0.16, 1, 0.3, 1)` | Scale and magnetic settles with a long tail. Pairs with 500ms. |
| `--ease-in-out-quart` | `ease-in-out-quart` | `cubic-bezier(0.76, 0, 0.24, 1)` | Reserved for on-screen moves that start and stop. |

### Durations

Tailwind duration utilities. Hover, focus and press flip in 100ms.

| Name | Class | Ms | Ease | Use |
| --- | --- | --- | --- | --- |
| instant | `duration-100` | 100 | `ease-mechanical` | Hover, focus, press, ink swaps |
| quick | `duration-150` | 150 | `ease-out-quart` | Covers, overlays, cell highlights |
| short | `duration-200` | 200 | `ease-out-quart` | Icon nudges, small translates |
| base | `duration-300` | 300 | `ease-out-quint` | Reveals, fade and slide, row arrows |
| slow | `duration-500` | 500 | `ease-out-expo` | Image fades, scale settles |
| scan | `duration-700` | 700 | `ease-mechanical` | Portrait scan and clip reveals |

### Rules

- Animate transform, opacity, color and clip-path. Do not animate layout properties.
- Hover and focus effects are CSS only. Gate hover-only inversions with `pointer-fine:` so touch never sticks.
- Every animation ships with a reduced-motion twin. The global rule below collapses all CSS durations; JavaScript motion branches on `useReducedMotion` from `hooks/use-reduced-motion`.
- GSAP comes from `motionKit` in `lib/motion/gsap.ts`.
- Agent motion: clip crossfade 0.38 s; scene loop 8 s; hover reaction shuffled deck of 8; reduced motion held key pose.

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

## Do and do not

### Do

- Use bg-paper, text-ink, text-graphite, text-mist and border-rule tokens.
- Set every annotation in the label utility and pair section labels with a jp annotation.
- Number panels as [ XX-NN ] LABEL 日本語 with a dotted leader and a count.
- Flip states in 100ms with ease-mechanical. Reveal with out-quart or out-quint.
- Keep hit areas at 44px on touch and use focus-visible rings.
- Build one base component with cva variants and merge classes with cn.
- Use Server Components by default and add use client only for interactivity.
- Mark where an agent stands with AgentWaypoint. Show a scene with AgentScene.
- Show a static meaningful fallback when WebGL is off.

### Do not

- Add a second Canvas or a per-component WebGL context.
- Use clay orange for UI chrome, links or buttons.
- Round corners. Radius is 0 everywhere.
- Hard-code hex or oklch values. Use the token class.
- Invent clients, metrics or achievements. Label placeholders as sample content.
- Write paragraphs where a label, a number or a specimen would do.
- Animate layout properties or ship motion without a reduced-motion twin.
- Write ad-hoc CSS classes. Style in markup with Tailwind utilities and cva variants.
- Add comments to code.
