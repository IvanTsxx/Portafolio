A subagent is a fresh agent with its own context window. It receives a brief, does the work and returns a summary.

## The test

I delegate when three things are true.

1. The work is independent of what the main thread just learned.
2. The result is checkable: a diff, a list of findings or a passing command.
3. I want the conclusion, not the forty files behind it.

## What I delegate and what I keep

| Task | Delegate | Why |
| --- | --- | --- |
| Find every use of an API | Yes | Large output, short answer |
| Rename a prop used in thirty files | Yes, to one agent | The typechecker verifies it |
| Design a data model | No | Needs full context |
| Two agents editing the same file | No | Shared writes serialize |

<Callout tone="tip" title="Read the diff, not the summary">
  A summary says what the agent meant to do. The diff shows what it did.
</Callout>
