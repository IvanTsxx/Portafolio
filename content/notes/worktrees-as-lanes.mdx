## Isolated and shared

| Thing                           | Scope    |
| ------------------------------- | -------- |
| Working files and branch        | Per lane |
| `node_modules` and build output | Per lane |
| Git objects and remotes         | Shared   |
| Stash stack                     | Shared   |

<Callout tone="warning" title="The stash is shared">
  A bare `git stash pop` can apply another lane's work. Commit a
  work-in-progress instead.
</Callout>

## Setting up a lane

```bash title="new-lane.sh"
git worktree add ../lane-hero -b lane/hero origin/main
cd ../lane-hero
bun install
bun dev --port 3105
```

Cut lanes along files, not features. Shared files get one owner.
