## Context

Editors recombine blocks without asking for code changes.

## Challenges

- Adding a block never edits an existing file.
- A block's shape is declared once.
- Safe previews and clear empty states.

## Implementation

<Steps>
  <Step title="Write the block module">
    Schema, query fragment, types and component in one file.
  </Step>
  <Step title="Register it">
    The module exports a definition. The registry collects them.
  </Step>
  <Step title="Render by type">
    The renderer looks the block up by type. No switch.
  </Step>
</Steps>

```ts title="blocks/registry.ts"
import type { ComponentType } from "react";

export interface BlockDefinition<Data> {
  type: string;
  Component: ComponentType<Data>;
}

export const defineBlock = <Data>(definition: BlockDefinition<Data>) =>
  definition;
```
