## Challenges

- Motion that reads well with every animation off.
- One timing scale for CSS and GSAP.
- Scroll effects that never hijack scrolling on touch.

```ts title="motion-tokens.ts"
export const durations = {
  fast: 0.2,
  base: 0.4,
  slow: 0.8,
} as const;

export const easings = {
  outQuart: "power3.out",
  outExpo: "expo.out",
} as const;
```

| Token  | Value | Used for                 |
| ------ | ----- | ------------------------ |
| `fast` | 0.2 s | Hover and focus feedback |
| `base` | 0.4 s | Entrances                |
| `slow` | 0.8 s | Scroll-linked reveals    |
