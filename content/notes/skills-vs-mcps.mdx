## Skills carry procedure

A skill is a folder with a `SKILL.md`. The agent loads it only when the task matches.

```md title=".claude/skills/ui-states/SKILL.md"
---
name: ui-states
description: Trigger when writing or reviewing UI code.
---

1. List the states before writing code.
2. Make states explicit with data attributes.
```

## MCP servers carry access

A server exposes tools over a standard interface. It needs credentials.

## How I decide

| Question                                | Reach for                        |
| --------------------------------------- | -------------------------------- |
| The agent repeats the same mistake      | A skill                          |
| The information lives in another system | An MCP server                    |
| The task needs both                     | A skill that names the MCP tools |

<Callout tone="tip" title="Rule of thumb">
  Write a skill the second time you correct the same mistake.
</Callout>
