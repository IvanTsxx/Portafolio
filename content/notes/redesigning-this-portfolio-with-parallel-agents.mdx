## I rejected the first proposals

The old navbar, footer and sidebar did not convince me at all. The lead agent then offered three common layouts: a thin top bar, a fixed left sidebar and a floating bottom dock. I said no to all three. I wanted something unique, smooth and premium that fit the style of the site.

I also set one condition. I would not touch the code. An AI would do everything.

## Three prototypes beat three descriptions

The lead agent ran a bakeoff. Three agents worked in parallel, each in its own git worktree, and each built a full chrome concept across every route:

- A, a drawing sheet with a title block.
- B, a dossier with a thumb index.
- C, a margin instrument.

A fourth agent built a dot grid experiment at the same time. I opened each concept on its own dev server, on ports 3001 to 3003, and picked B. Clicking through three real builds made the choice. A written comparison would not have.

## The rest came in rounds

After the pick, the work ran in rounds. Every agent ran Opus at medium effort in its own worktree, with a file scope it owned. The lead merged each round into one branch, and later into main. The rounds covered:

- One companion Claude, the How I work 3D stages and the Workshop.
- A rework of the home sections and the hero dither field.
- Japanese annotations cut from about 86 usages to 3 places.
- A `design.md` audit that took the file from 201 to 112 lines.
- An SEO audit with per-route metadata, JSON-LD and a check over the built HTML.
- A redesign of Experience and Pinned, new experiments and registry pruning.

## Tests hold the decisions

Each round left a guardrail behind:

- Every prop on a 3D stage stays inside the camera frame on every loop frame. This test caught two clipped scenes.
- Only one agent can render on screen.
- The thumb-index notches match the section headings.
- Every route passes an SEO test, and `bun run seo:check` reads the built HTML.
- Privacy tests keep my employer to its name, role, dates and link.

No agent used browser automation. Verification was typecheck, oxlint, ultracite, `bun test`, `next build` and the SEO check. I looked at the dev server and sent screenshots.
