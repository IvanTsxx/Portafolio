Dithering turns a gray image into black and white dots that still read as gray. There are two families of methods, and this site uses only one of them.

## Ordered dithering is one threshold per pixel

A Bayer matrix holds a threshold for every position in a small tile. Each pixel compares its brightness with the threshold at its position in the tile:

```ts
const bayer4 = [0, 8, 2, 10, 12, 4, 14, 6, 3, 11, 1, 9, 15, 7, 13, 5];

const isInk = (x: number, y: number, brightness: number) =>
  brightness < (bayer4[(y % 4) * 4 + (x % 4)] + 0.5) / 16;
```

No pixel depends on another. That makes ordered dithering parallel, and a good fit for a GPU.

Every dither on this site is ordered:

- The GitHub portrait, a 4×4 Bayer drawn with Canvas2D. On hover, the rows drift.
- The page heroes, a 4×4 Bayer over seeded noise.
- The Speed smear, Super Saiyan and Vegeta experiments, an 8×8 Bayer in the fragment shader.

## Error diffusion runs in order

Error diffusion rounds each pixel to black or white, then pushes the rounding error to neighbors that are not processed yet. Floyd–Steinberg sends it right and down:

```ts
const error = brightness - (brightness < 0.5 ? 0 : 1);
pixels[i + 1] += (error * 7) / 16;
pixels[i + width - 1] += (error * 3) / 16;
pixels[i + width] += (error * 5) / 16;
pixels[i + width + 1] += (error * 1) / 16;
```

Every pixel waits for the ones before it. The work is sequential, so it runs on the CPU.

## Which one to pick

I use Bayer for anything that animates, because every frame is a cheap parallel pass. Error diffusion fits a still image that changes rarely, where one sequential pass on the CPU is fine. The error diffusion experiment is gone, so every dither here is Bayer.
