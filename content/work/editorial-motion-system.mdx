## Challenges

- Motion that reads well with every animation switched off.
- One timing scale shared by CSS transitions and GSAP timelines.
- Scroll effects that never hijack scrolling on touch devices.

## Contribution

State plainly what you owned and what the team owned. Keep each responsibility specific enough that a reviewer could ask about it.

### Motion tokens

Durations and easings live in one place so a designer can change them without reading a timeline.

### Choreography

Sequences are written once and reused. Each one declares its reduced-motion composition up front.

## Implementation

<Steps>
  <Step title="Define the tokens">
    Name every duration and easing once. Reference the names everywhere else.
  </Step>
  <Step title="Build the sequence">
    Scope each timeline to a container ref so cleanup is automatic.
  </Step>
  <Step title="Write the fallback">
    Render the final state when the visitor asks for reduced motion.
  </Step>

```ts title="motion-tokens.ts"
export const durations = {
  fast: 0.2,
  base: 0.4,
  slow: 0.8,
} as const;

export const easings = {
  outQuart: "power3.out",
  outExpo: "expo.out",
} as const;
```

| Token  | Value | Used for                 |
| ------ | ----- | ------------------------ |
| `fast` | 0.2 s | Hover and focus feedback |
| `base` | 0.4 s | Entrances                |
| `slow` | 0.8 s | Scroll-linked reveals    |
