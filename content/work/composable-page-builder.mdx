## Context

Describe the site, the editors and the number of block types. A page builder earns its keep when editors recombine blocks without asking for code changes.

## Challenges

- Adding a block must never require editing an existing file.
- The shape of a block should be declared once and derived everywhere else.
- Editors need safe previews and clear empty states.

## Implementation

<Steps>
  <Step title="Write the block module">
    One file owns the schema, the query fragment, the types and the component.
  </Step>
  <Step title="Register it">
    The module exports a definition. The registry collects definitions in one
    place.
  </Step>
  <Step title="Render by type">
    The renderer looks the block up by its type. There is no switch over block
    types.
  </Step>
</Steps>

```ts title="blocks/registry.ts"
import type { ComponentType } from "react";

export interface BlockDefinition<Data> {
  type: string;
  Component: ComponentType<Data>;
}

export const defineBlock = <Data>(definition: BlockDefinition<Data>) =>
  definition;
```
