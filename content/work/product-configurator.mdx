## Implementation

### Loading the canvas

The canvas loads from a client wrapper with `ssr: false` and renders the static image until it is ready.

```tsx title="configurator-canvas.tsx" {4-6}
import dynamic from "next/dynamic";

export const ConfiguratorCanvas = dynamic(
  () => import("./configurator-scene"),
  { ssr: false, loading: () => <ConfiguratorPoster /> }
);
```

### Keeping interface and scene in sync

Variant state lives outside the scene. The scene reads it and never owns it.

| State            | Owner | Read by           |
| ---------------- | ----- | ----------------- |
| Selected variant | Page  | Scene and summary |
| Camera viewpoint | Page  | Scene             |
| Loaded assets    | Scene | Poster fallback   |
